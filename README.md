# KillDeathMonitor
description:

"KillDeathMonitor" is a plugin for IW4MAdmin that displays custom messages to players whenever a death or a killstreak occurs, informing both the killer and the victim in real time during the match.

instructions

just put it in the "Plugins" folder inside your "IW4MAdmin"
